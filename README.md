**یاروان** از «یار» و «کاروان» ساخته شده است. این پروژه نسخهٔ مستقلی از بخش متن‌باز [OpenMausBot](https://github.com/milind-soni/OpenMausBot) است؛ نه محصول رسمی آن پروژه و نه یک سرویس ابری. برای هر بات می‌توانی مدل مناسب خودت را انتخاب کنی. فایل‌های دادهٔ برنامه روی میزبان خودت ذخیره می‌شوند. مدل ابری، تلگرام و اپ‌های متصل فقط با پیکربندی تو فعال می‌شوند و حسب قابلیت، دادهٔ لازم را دریافت می‌کنند.

## چه چیزهایی اضافه شده؟

| قابلیت | چطور استفاده می‌کنی؟ |
|---|---|
| **حافظهٔ فقط همین پروژه** | هنگام ساخت پوشه، **Project-only memory** را بزن. گفت‌وگوهای جدید آن پوشه فقط دفتر، سنجاق‌ها و سابقهٔ همان پروژه را به‌عنوان حافظه می‌بینند. حالت محدود ابزارهای متصل ندارد. |
| **بازیابی ترکیبی محلی** | اگر Ollama و مدل بردارساز محلی را تنظیم کنی، تطبیق معنایی کنار جست‌وجوی کلمه‌ای به کار می‌رود. با قطع Ollama جست‌وجوی کلمه‌ای باقی می‌ماند. |
| **تلگرام خصوصی** | پل اختیاری از Telegram Bot API پیام متنی فقط یک شناسهٔ مجاز را می‌گیرد؛ از مسیر محدود یک بات اختصاصی پاسخ می‌دهد. گروه، حافظهٔ عمومی و اجرای ابزار ندارند. |
| **آموزش با نمایش در مرورگر** | کنترل مرورگر موقت را بگیر و **Teach in this browser** را بزن. کلیک و اسکرول تبدیل به پیش‌نویس قابل‌ویرایش می‌شوند. نه متن تایپ‌شده ثبت می‌شود و نه پیش‌نویس خودکار اجرا می‌شود. |

کنترل‌های قبلی حافظه حفظ شده‌اند: سنجاق‌کردن پیام یا بخش انتخابی، سنجاق مخصوص پروژه، چت بدون حافظه، نمایش زمینهٔ حافظه‌ای پاسخ، و تأیید یادگیری پیش از ذخیره. **چت بدون حافظه هنوز در تاریخچهٔ محلی می‌ماند.**

## اجرای محلی از سورس

نیازمندی: **Node.js 24+**، **pnpm 10.33.0** و یک موتور مدل سازگار. این بسته نصاب دسکتاپ یا سرویس آمادهٔ میزبانی نیست.

```bash
corepack enable # or install pnpm 10.33.0 separately if Corepack is absent
pnpm install --frozen-lockfile --ignore-scripts
```

ترمینال ۱، از ریشهٔ پروژه:

```bash
OMB_DATA_DIR="$HOME/.yarvan" OMB_DISABLE_ANNOUNCEMENTS=1 pnpm dev:server
```

ترمینال ۲:

```bash
pnpm dev
```

در مرورگر `http://127.0.0.1:5199` را باز کن. برای ارسال اولین پیام باید یک موتور مثل Claude Code یا یک API سازگار را در تنظیمات انتخاب و پیکربندی کنی. مسیر مستقل `~/.yarvan` کمک می‌کند روی دادهٔ نصب قبلی کار نکنی. تنظیمات واقعی، توکن‌ها و فایل‌های داده را وارد Git نکن.

برای فعال‌کردن جست‌وجوی محلی یا تلگرام، مثال قدم‌به‌قدم در **[راهنمای فارسی](docs/yarvan/guide-fa.md)** است. **[حدود دسترسی و نحوهٔ نگهداری داده](docs/yarvan/architecture.md)** و **[تست‌های قابل‌تکرار](docs/yarvan/verification.md)** هم در مخزن‌اند.
