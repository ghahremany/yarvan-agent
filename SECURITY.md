# Security reporting

If this repository is hosted on GitHub, use its private **Report a vulnerability** option when available. Avoid putting an unpatched vulnerability, access token, browser state, or private transcripts in a public issue. For an issue confined to the upstream OpenMausBot project, use [its security policy](https://github.com/milind-soni/OpenMausBot/security/policy).

Use a single-owner test workspace, synthetic chats, and redacted diagnostics when reproducing an issue. Do not run unknown workloads against someone else's data or services. See [Yarvan's data boundaries](docs/yarvan/architecture.md).
