# نصب یاروان و اتصال اندروید

[صفحهٔ دریافت نسخه‌های یاروان](https://github.com/ghahremany/yarvan-agent/releases) · [صفحهٔ محصول](https://ghahremany.github.io/yarvan-agent/)

## ویندوز x64

1. از نسخهٔ آزمایشی، فایل `*-windows-x64-setup.exe` را بگیر.
2. چک‌سام را با `SHA256SUMS.txt` همان انتشار تطبیق بده. در PowerShell: `Get-FileHash .\Yarvan-0.1.1-beta.1-windows-x64-setup.exe -Algorithm SHA256`.
3. نصاب را اجرا و از Start، **Yarvan** را باز کن. لازم نیست Node.js یا pnpm روی رایانه نصب باشد. نصاب Authenticode ندارد؛ ممکن است ویندوز آن را ناشر ناشناس بنامد. اگر سیاست سازمان نصب را مسدود می‌کند، آن را دور نزن.
4. مدل یا موتور دلخواهت را در تنظیمات فعال کن. نصب خود برنامه جای حساب و ابزار ارائه‌دهندهٔ مدل را نمی‌گیرد.

## لینوکس x86_64

روی Ubuntu 24.04، `.deb` پیشنهاد می‌شود چون APT وابستگی‌ها را نصب می‌کند و سیاست محدود مرورگر روی **مسیر همین بسته** اعمال می‌شود:

```bash
sha256sum Yarvan-0.1.1-beta.1-linux-amd64.deb
sudo apt install ./Yarvan-0.1.1-beta.1-linux-amd64.deb
```

از منوی برنامه‌ها **Yarvan** را باز کن. برنامه و سرور محلی‌اش داخل بسته‌اند. دادهٔ پیش‌فرض دسکتاپ `~/.yarvan` است و به دادهٔ نصب OpenMausBot دست نمی‌زند. این نسخه فایل پیشرفتهٔ به‌روزرسان خودکار ندارد؛ نسخه‌ها را از صفحهٔ Releases بگیر.

AppImage فایل قابل حمل است. در توزیع‌هایی که sandbox Chromium و کتابخانه‌های Electron را پشتیبانی می‌کنند، به فایل مجوز اجرا بده (`chmod +x نام‌فایل.AppImage`) و آن را باز کن. Ubuntu 24.04 محدودیت‌های namespace دارد؛ اگر AppImage باز نشد، **نسخهٔ `.deb`** را انتخاب کن و sandbox یا AppArmor را خاموش نکن.

## اندروید (۸ به بعد)، برنامهٔ همراه

1. `*-android.apk` را از انتشار رسمی همین مخزن بگیر. فقط اگر چک‌سام همان انتشار درست است نصب کن. اگر گوشی اجازهٔ نصب فایل خارج از فروشگاه را درخواست کرد، فقط به برنامه‌ای که همین فایل را باز می‌کند و فقط برای زمان نصب اجازه بده.
2. یاروان را روی رایانه یا سرور روشن نگه دار. گوشی باید به **نشانی HTTPS فضای کار** با گواهی معتبر اندروید دسترسی داشته باشد. صفحهٔ محصول GitHub Pages، `localhost` یا نشانی `http://` فضای کار نیستند.
3. روش پیشنهادی دسکتاپ: روی گوشی و رایانه به یک tailnet شخصی Tailscale وصل شو، MagicDNS و HTTPS Certificates را برای آن فعال کن. در یاروان **Settings → Phone & devices → Your other computers** را فعال کن. وقتی نشانی `https://…ts.net` آماده شد، از **Pair a computer → Copy link** لینک دوازده‌حرفی جفت‌سازی مرورگر را بگیر، نه QR یا کد شش‌رقمی **Pair a phone**. این APK از همان رابط وب میزبان استفاده می‌کند.
4. در **همراه یاروان**، پیوند جفت‌سازی HTTPS را وارد کن و **باز کردن فضای کار** را بزن. پیوند یک‌بارمصرف را عمومی نکن. برنامه فقط نشانی میزبان را برای دفعات بعد نگه می‌دارد؛ نشست توسط رابط وب اداره می‌شود. اگر دسترسی از بین رفت، پیوند تازه بگیر. دستگاه گمشده را از صفحهٔ اتصال دستگاه‌ها روی میزبان لغو کن.

اگر از سرور خودمیزبان استفاده می‌کنی، HTTPS و جفت‌سازی مرورگر را مانند [راهنمای خودمیزبانی](../self-hosting.md) تنظیم کن؛ از سورس یاروان استفاده کن، نه `npx openmausbot`. پورت loopback دارای اعتماد مالک را مستقیم روی اینترنت باز نکن. برای جفت‌سازی، لینک HTTPS `/pair` را از یک نشست مالک مطمئن و ترجیحاً با دسترسی محدود به چت بگیر. ورود به سرویس‌های دیگر را روی میزبان انجام بده؛ برنامه ناوبری به میزبان دیگر، HTTP و گواهی نامعتبر را رد می‌کند. به‌روزرسانی Android System WebView توصیه می‌شود.

این APK برنامهٔ مدیریت و چتِ متصل به میزبان است. عامل محلی اندروید، آفلاین، اعلان Push و API بومی رله ندارد. یک دستگاه واقعی و اتصال Tailscale هر کاربر هنوز باید جداگانه بررسی شود.
