## یاروان ۰٫۱٫۱ — نخستین نصاب‌های آزمایشی

- **ویندوز ۶۴ بیتی (x64):** فایل `Yarvan-0.1.1-beta.1-windows-x64-setup.exe`. نصاب گواهی Windows Authenticode ندارد؛ ممکن است Windows ناشر را ناشناس نشان دهد. نسخهٔ ARM64 جداگانه نیست.
- **لینوکس ۶۴ بیتی (x64):** `Yarvan-0.1.1-beta.1-linux-amd64.deb` برای Ubuntu 24.04 توصیه می‌شود؛ با `sudo apt install ./نام‌فایل.deb` نصب کن. `Yarvan-0.1.1-beta.1-linux-x86_64.AppImage` قابل حمل است و به پشتیبانی توزیع از sandbox نیاز دارد. روی Ubuntu بستهٔ `.deb` را انتخاب کن، نه خاموش کردن sandbox.
- **اندروید ۸ به بعد:** `Yarvan-0.1.1-beta.1-android.apk` برنامهٔ **همراه** و امضاشده است؛ به یاروانِ در حال اجرا روی رایانه یا سرورت با نشانی HTTPS معتبر نیاز دارد. اجرای عامل‌ها روی گوشی، Push، رلهٔ بومی و انتشار در Play Store در این نسخه نیست.

[راهنمای فارسی نصب و اتصال گوشی](https://github.com/ghahremany/yarvan-agent/blob/main/docs/yarvan/install-fa.md)

میزبان اجرا و حافظه را نگه می‌دارد. ابتدا مدل را روی میزبان تنظیم کن. نصاب‌ها به‌روزرسان خودکار به OpenMausBot یا ثبت پروتکل آن ندارند. کنترل بومی رایانه و ابزار USB اندروید به‌صورت همراه این بسته‌ها توزیع نمی‌شوند. تلگرام و Ollama تنظیم جداگانه می‌خواهند. انتشار آزمایشی به معنی تأیید همهٔ موتورهای مدل، توزیع‌ها یا دستگاه‌های واقعی نیست.

## English

Windows x64 NSIS installer (unsigned), Linux amd64 DEB (recommended on Ubuntu 24.04) and x86_64 AppImage, and a signed Android 8+ HTTPS workspace companion. The APK does not run agents on-device. Compare file hashes with `SHA256SUMS.txt`; the beta APK certificate fingerprint is published separately. Desktop smoke tests run on freshly installed Windows and Ubuntu packages. The AppImage filesystem and the Android APK package/signature are checked. The host-side pairing, session recovery and revocation flow was exercised over HTTPS; the APK has not been tested on a physical Android device. [Installation and pairing guide](https://github.com/ghahremany/yarvan-agent/blob/main/docs/yarvan/install.md).
